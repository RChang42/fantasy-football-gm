# Fantasy Football GM

Fantasy Football GM is a personal, non-commercial fantasy football decision-support application being developed for use with my own Yahoo Fantasy Football team and league.

## Purpose

The project is intended to help a fantasy football manager make better roster and lineup decisions by combining authorized Yahoo Fantasy Sports data with football projections, injury information, news, and statistical analysis.

The application is currently intended for a single user and a single Yahoo Fantasy Football league. It is not a commercial product or public fantasy data service.

## Yahoo Fantasy Sports API Usage

The application will request read-only access to Yahoo Fantasy Sports data associated with the authenticated user's fantasy league.

The application may retrieve data such as:

* League settings and scoring rules
* Fantasy teams and rosters
* Player information
* Available players and waiver-wire information
* Matchups and standings
* League transactions

Yahoo Fantasy Sports data will be used to provide personalized analysis and recommendations for the authorized user.

## Planned Features

Fantasy Football GM is intended to provide:

* Weekly lineup analysis and start/sit recommendations
* Waiver-wire analysis
* Roster construction and positional need analysis
* Player comparison and valuation
* Trade analysis
* Matchup analysis
* Injury and player-news monitoring
* Rest-of-season and playoff-oriented roster analysis

## Data and Access

Yahoo Fantasy Sports API access will be read-only.

The project will not use the Yahoo Fantasy Sports API to automatically modify lineups, submit waiver claims, execute trades, or perform other write operations.

Yahoo Fantasy Sports data obtained by the application is intended solely for personal fantasy football analysis. The project is not intended to resell, redistribute, or commercially expose Yahoo Fantasy Sports data.

## Project Status

This project is currently in early development and is intended initially for personal, non-commercial use by one user in one Yahoo Fantasy Football league.
